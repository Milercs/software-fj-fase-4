Sistema Integral de Gestión de Clientes, Servicios y Reservas
Proyecto correspondiente a la Fase 4 del componente práctico del curso Programación, código 213023, de la Universidad Nacional Abierta y a Distancia.

Descripción
El proyecto implementa un sistema orientado a objetos para la empresa Software FJ. El sistema permite gestionar clientes, servicios y reservas sin utilizar bases de datos.

La información se administra mediante objetos y listas internas. También se utiliza un archivo de logs para registrar eventos y errores producidos durante la ejecución.

Funcionalidades previstas
Registro y validación de clientes.
Gestión de reserva de salas.
Gestión de alquiler de equipos.
Gestión de asesorías especializadas.
Creación, confirmación, cancelación y procesamiento de reservas.
Cálculo de costos con impuestos y descuentos.
Manejo de excepciones personalizadas.
Registro de eventos y errores.
Simulación de operaciones válidas e inválidas.
Requisitos
Python 3.12 o una versión compatible.
No requiere librerías externas.
No utiliza base de datos.
